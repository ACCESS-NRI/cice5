
## Overview
This branch contains the CICE5 version used within ACCESS-ESM1.6. It was forked from https://code.metoffice.gov.uk/trac/cice/browser/main/branches/pkg/Config/vn5.1.2_GSI8.1_package_branch/cice?order=name&rev=334#source (MOSRS account required), which in turn captured the trunk from the subversion (svn) repository of the Los Alamos Sea Ice Model, version 5.1.2. It has significantly diverged to support ACCESS coupling (with UM7.3 atmoshpere) and contains some differences from the ACCESS-OM2 branch of CICE5 (master). 

More recent versions are found in the [CICE](https://github.com/CICE-Consortium/CICE) and [Icepack](https://github.com/CICE-Consortium/Icepack) repositories, which are maintained by the CICE Consortium. For significant developments and new features, we suggest using those models.

There is [PDF documentation](https://github.com/ACCESS-NRI/cice5/blob/master/doc/cicedoc.pdf) available for CICE 5.1.2, however changes were made to this branch to support coupling with ACCESS-ESM1.6.
